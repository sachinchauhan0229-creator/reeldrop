ReelDrop REST API

The API uses the same extractor as the website. There is no API key or paid media provider in the default setup. Requests are rate-limited; public availability is determined by Instagram.

Look up media

POST https://reeldrop.jobcraft.in/api/direct
Content-Type: application/json

{"url":"https://www.instagram.com/p/POST_ID/","mode":"all"}

Modes: all, video, photo, reels, story, igtv, carousel and viewer. Viewer accepts a public username as well as a post link.

Response

A successful response includes sourceUrl, kind, a media array, optional post/profile metadata and warnings. Each media item has its type, available variants, dimensions and a thumbnail when available. The website filters modes using these types.

Download a returned item

POST https://reeldrop.jobcraft.in/api/save
Content-Type: application/json

{"source":"RETURNED_INSTAGRAM_CDN_URL","filename":"my-media"}

The response streams a photo or video as an attachment. Only approved Instagram CDN hosts and safe image/video MIME types are accepted. Never send account passwords, session cookies or private files.

Errors and limits

Errors contain error and code. Invalid inputs return 400, inaccessible media generally returns 422/404, and throttled requests return 429. Limits are best-effort per server instance and hosting allowances still apply. Story and public-profile access may be restricted by Instagram. No private-account access, follower-list API or account-search API is implemented.
