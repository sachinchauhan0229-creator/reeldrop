GOOD TO KNOW

Clear answers.
Fewer surprises.

Only accessible public content is supported.

Can I save photos and carousel posts?

Yes. The app can parse public photo posts and mixed photo/video carousels. You can select a quality, save each item or create a ZIP of selected items. ZIP creation is limited to 60 MB in the browser; larger albums can be saved individually.

What quality is available?

Quality choices come from actual media returned by Instagram. ReelDrop does not invent higher resolutions, upscale files or add a watermark.

Will Stories and profiles always work?

No. Instagram often requires login or restricts server access even for public accounts. The app tries accessible public Story, Highlight and profile URLs, and shows an error when retrieval is restricted. It does not ask for passwords or promise invisible access.

Are private accounts supported?

No. This tool does not bypass private account controls or use your account credentials.

Do I need to install an app?

No. The site works in your browser. You can optionally install the web app on a supported device.

Can I use an API or an AI assistant?

The same public-media lookup is available through the REST API and our MCP endpoint. Both have request limits and the same Instagram access restrictions.

Can I use an address-bar shortcut?

Use https://reeldrop.jobcraft.in/?url=INSTAGRAM_LINK to open the downloader with a link filled in. You can also prefix an Instagram URL with this site’s address; the fallback page will open the main form.
