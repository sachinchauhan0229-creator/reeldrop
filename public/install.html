Install ReelDrop

ReelDrop is an installable web app. It uses the same website and downloader, without a separate account.

Android

Open ReelDrop in a compatible browser, then use its Install app or Add to Home screen menu. The exact wording depends on your browser.

iPhone and iPad

Open the site in Safari, tap Share, then Add to Home Screen. The downloader still depends on your browser’s file-saving behavior.

Desktop

Use the browser’s installation icon or its Install app menu when available. Installation is optional; the normal website provides the same tools.

What works offline?

The basic app shell can open offline, but Instagram lookup, previews and downloads require internet access. Media and lookup results are not stored in the service-worker cache.

Address-bar shortcut

Open https://reeldrop.jobcraft.in/?url=https://www.instagram.com/reel/POST_ID/ to prefill the form. Or put this site’s address before a full Instagram URL. Always use a post you own or have permission to save.

Android APK

No signed Android APK is distributed by this project. The installable web app is the supported mobile option. Only install software from a source you trust.
