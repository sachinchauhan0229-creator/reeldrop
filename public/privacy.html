Privacy notice

Last updated: 15 October 2026. Operator: Sachin Chauhan.

Links you submit

Your entered link is sent to the site's API when you request a download. The submitted public post URL is processed by this site’s backend using yt-dlp, which makes requests directly to Instagram. No Apify service is called. Instagram receives the backend’s network requests; the application does not save links or downloaded media to its own database.

Technical data

The hosting service may process request metadata, such as IP addresses, timestamps and diagnostic logs. Retention depends on the host's settings and policies. The API uses IP addresses temporarily in memory for basic per-instance throttling, with entries cleared after their request window expires. This application currently includes no analytics, advertising scripts, account system or application cookies.

Fonts and clipboard

The interface uses system fonts and makes no external font requests. The Paste button asks your browser for clipboard access when you click it; you can instead paste manually.

Contact and email

For privacy questions, email sachinchauhan0229@gmail.com. Information you send by email is used to address your request and may be processed by the email provider.

Future changes

This notice must be updated when a media provider, analytics, advertising, accounts or other data processing is introduced. Never submit Instagram credentials.
