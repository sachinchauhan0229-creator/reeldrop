ReelDrop MCP

The stateless HTTP endpoint exposes two read-only public-media tools. It shares the website’s availability restrictions and request limits; no private accounts, follower lists or Instagram login credentials are supported.

Connect your client

{
  "mcpServers": {
    "reeldrop": {
      "type": "http",
      "url": "https://reeldrop.jobcraft.in/api/mcp"
    }
  }
}

Use your MCP client’s supported remote-server configuration. Client capabilities differ; this endpoint returns JSON-RPC responses and does not require OAuth.

Available tools

  • get_instagram_media: accepts a public post, Reel, carousel or Story URL and returns available media/quality metadata.
  • get_instagram_profile: accepts a public username and returns profile information when anonymous access is permitted.

Example requests

Ask your client to inspect a public Reel, list the photos/videos in a carousel, or return available quality choices. A tool error means the media was not accessible; it is not proof that an account is private or a post has been removed.

Protocol

The endpoint implements initialization, ping, tool listing, tool calls and initialized notifications. It supports a stateless Streamable HTTP JSON response flow. Long-lived subscriptions and follower/comment scraping are not provided.
